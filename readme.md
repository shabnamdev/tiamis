# Tiamis – AI Live Chat

**Version:** 1.0.0
**Plugin slug:** `tiamis-ai-live-chat`
**Developer:** SHABNAM.DEV
**WordPress:** 7.0 or later
**PHP:** 7.4 or later
**License:** GPL-2.0-or-later

تیامیس یک افزونه گفتگوی زنده چندزبانه برای وردپرس است که پیام‌های سایت، تلگرام و بله را در یک صندوق پشتیبانی یکپارچه می‌کند و امکان استفاده از پاسخ‌یار هوش مصنوعی، اعلان مرورگر و ابزارهای مدیریت گفتگو را در اختیار تیم پشتیبانی قرار می‌دهد.

## قابلیت‌های نسخه 1.0.0

- ویجت گفتگوی شناور و شورت‌کد `[shcd_tiamis]`
- صندوق یکپارچه گفتگوها در مدیریت وردپرس
- اتصال به ربات‌های Telegram و Bale
- رابط فارسی، عربی و انگلیسی با پشتیبانی RTL/LTR
- پاسخ‌یار هوشمند با Cloudflare Workers AI در نسخه رایگان؛ OpenRouter، Ollama و سرویس‌های سازگار با OpenAI به‌صورت گزینه‌های قفل‌شده PRO نمایش داده می‌شوند
- حالت پیشنهاد پاسخ و پاسخ خودکار
- مدیریت اپراتورها، تخصیص گفتگو، اولویت، برچسب، یادداشت و وظایف
- پیوست، واکنش، امتیازدهی و گزارش پیام نامناسب
- Web Push و اعلان داخلی مرورگر
- کنترل رضایت، شیوه نگهداری IP و دوره نگهداری داده‌ها
- ابزارهای Export و Erase حریم خصوصی وردپرس
- پنل مدیریتی واکنش‌گرا با بارگذاری داخلی و بازگشت ایمن به صفحات استاندارد وردپرس
- بارگذاری اختیاری فونت اختصاصی برای رابط تیامیس

## قابلیت‌های PRO

در نسخه حاضر، بخش‌های زیر فقط به‌صورت پیش‌نمایش قفل‌شده نمایش داده می‌شوند و منطق اجرایی، تنظیمات، جدول‌های داده، مسیرهای عمومی API و شورت‌کدهای آن‌ها در بسته رایگان وجود ندارد:

- سامانه ثبت، پیگیری و مدیریت تیکت
- نقشه حرارتی تعامل و کلیک کاربران
- REST API خارجی و Webhook خروجی

تب‌های این قابلیت‌ها با محتوای محوشده، نشان طلایی **PRO** و پیام رسمی متناسب با زبان فعال پنل نمایش داده می‌شوند.

## نصب

1. فایل ZIP را از مسیر **افزونه‌ها ← افزودن افزونه تازه ← بارگذاری افزونه** نصب کنید.
2. افزونه **Tiamis – AI Live Chat** را فعال کنید.
3. وارد **تیامیس ← تنظیمات** شوید.
4. زبان، ویجت، اپراتورها، ربات‌ها، اعلان‌ها و سرویس هوش مصنوعی موردنیاز را تنظیم کنید.

ویجت شناور می‌تواند به‌صورت خودکار نمایش داده شود. برای قراردادن چت در محل دلخواه از شورت‌کد زیر استفاده کنید:

```text
[shcd_tiamis]
```

## هوش مصنوعی

پاسخ‌یار می‌تواند در حالت پیش‌نویس برای اپراتور یا پاسخ خودکار اجرا شود. در نسخه رایگان فقط Cloudflare Workers AI فعال است و سایر Providerها در فهرست با نشان PRO و به‌صورت غیرفعال دیده می‌شوند. پیش از فعال‌کردن پاسخ خودکار، کیفیت مدل، سیاست پردازش داده سرویس‌دهنده و Prompt اصلی را بررسی کنید. کلیدها و Tokenها در صورت پشتیبانی سرور با Sodium یا OpenSSL رمزگذاری می‌شوند.

## امنیت و حریم خصوصی

- بررسی Capability و Nonce برای عملیات مدیریتی
- Rate Limit و Honeypot برای مسیرهای عمومی گفتگو
- کنترل SSRF در اتصال سرویس‌های بیرونی
- حذف داده‌های حساس از گزارش‌های فنی
- اجرای لاگ فنی فقط با فعال‌بودن هم‌زمان Debug وردپرس و گزینه افزونه
- انتخاب عدم ذخیره IP، هش HMAC یا IP کامل
- دوره نگهداری قابل‌تنظیم برای داده‌های گفتگو
- پشتیبانی از ابزارهای Export و Erase وردپرس

## داده‌های افزونه

نسخه 1.0.0 فقط جدول‌های موردنیاز گفتگوی زنده، پیام‌ها، نگاشت ربات‌ها، گزارش‌ها، یادداشت‌ها، برچسب‌ها، پیوست‌ها، واکنش‌ها، پایگاه دانش و Audit را ایجاد می‌کند. جدول‌های تیکت، دپارتمان و رویدادهای Heatmap در این بسته ایجاد نمی‌شوند.
