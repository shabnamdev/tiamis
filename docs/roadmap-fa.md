# مسیر توسعه Tiamis

نسخه پایه افزونه با شماره 1.0.0 بر گفتگوی زنده چندزبانه، صندوق کارشناسان، اتصال Telegram و Bale، اعلان‌ها و پاسخ‌یار هوش مصنوعی متمرکز است.

## قابلیت‌های برنامه‌ریزی‌شده برای PRO

1. **سامانه تیکتینگ هوشمند:** پرتال چندزبانه ثبت و پیگیری، کد رهگیری امن، دپارتمان، گردش وضعیت، پاسخ کارشناسان و شورت‌کدهای اختصاصی.
2. **نقشه حرارتی:** ثبت کنترل‌شده کلیک‌ها، تحلیل تراکم تعامل، رتبه‌بندی صفحات و گزارش‌های بصری با ملاحظات حریم خصوصی.
3. **External API و Webhook:** REST API احراز هویت‌شده، Webhook امضاشده و اتصال امن به CRM و ابزارهای اتوماسیون.

این قابلیت‌ها در نسخه رایگان فقط به‌صورت تب قفل‌شده و چندزبانه معرفی می‌شوند و هیچ پیاده‌سازی اجرایی، تنظیم فعال، جدول داده، مسیر API یا شورت‌کد مربوط به آن‌ها در بسته 1.0.0 وجود ندارد.

## پیشنهادهای فازهای بعدی

- WebSocket یا SSE برای تحویل بلادرنگ پیام با مصرف کمتر منابع
- RAG با استناد منبع از نوشته‌ها، محصولات و پایگاه دانش تأییدشده
- یکپارچه‌سازی WooCommerce و WHMCS برای نمایش اطلاعات مشتری کنار گفتگو
- Workflow Builder برای پاسخ‌های آماده، ساعات کاری و مسیردهی گفتگو
- داشبورد سلامت اتصال Telegram، Bale، AI و Web Push
- رمزنگاری سطح پیام و گردش کلید برای سازمان‌های حساس
- حذف یا ناشناس‌سازی انتخابی مکالمه همراه Audit Log
- ترجمه ماشینی مکالمه با نگهداری متن اصلی و ترجمه‌شده

هر قابلیت جدید باید پیش از انتشار از نظر حداقل‌گرایی داده، کنترل دسترسی، Rate Limit، ثبت Audit، سازگاری چندزبانه و مسیر مهاجرت پایگاه داده بررسی شود.
