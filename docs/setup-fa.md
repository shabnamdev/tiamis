# راهنمای راه‌اندازی Tiamis – AI Live Chat 1.0.0

## ۱. نصب اولیه

فایل ZIP باید پوشه ریشه `tiamis-ai-live-chat` و فایل اصلی `shcd-tiamis.php` را داشته باشد. افزونه را از مسیر «افزونه‌ها ← افزودن افزونه تازه ← بارگذاری افزونه» نصب و فعال کنید.

## ۲. زبان پنل و ویجت

پنل مدیریت از فارسی، عربی و انگلیسی پشتیبانی می‌کند. فارسی و عربی با چینش RTL و انگلیسی با چینش LTR نمایش داده می‌شوند. زبان ویجت سایت مستقل از زبان پنل و از تب «ویجت و تجربه کاربر» قابل تنظیم است.

عنوان و پیام بخش‌های قفل‌شده PRO نیز با تغییر زبان پنل به‌صورت پویا ترجمه می‌شوند.

## ۳. راه‌اندازی گفتگوی سایت

1. وارد «تیامیس ← تنظیمات ← ویجت» شوید.
2. نمایش Bubble Chat، رنگ‌ها، موقعیت و فرم پیش از گفتگو را تنظیم کنید.
3. برای نمایش چت در محل دلخواه، شورت‌کد `[shcd_tiamis]` را در برگه یا نوشته قرار دهید.
4. یک پیام آزمایشی بفرستید و ثبت آن را در صندوق گفتگوها بررسی کنید.

## ۴. اپراتورها و صندوق گفتگو

نقش‌های اختصاصی اپراتور و سرپرست از Capabilityهای تیامیس استفاده می‌کنند. دسترسی‌های صندوق، پاسخ، گزارش و تنظیمات را فقط به کاربران موردنیاز بدهید. تخصیص گفتگو، اولویت، برچسب، یادداشت و وظیفه از داخل صندوق مدیریت می‌شود.

## ۵. اتصال Telegram

1. از BotFather ربات بسازید و Token را دریافت کنید.
2. Chat ID اپراتورها یا گروه پشتیبانی را وارد کنید.
3. اتصال Telegram را فعال کنید.
4. Webhook یا Polling را متناسب با محدودیت میزبانی تنظیم کنید.
5. از سایت پیام بفرستید و پاسخ Reply ربات را در همان گفتگو بررسی کنید.

برای Webhook، سایت باید HTTPS عمومی و قابل دسترس از اینترنت داشته باشد. Secret Token و جلوگیری از پردازش Update تکراری در هسته اتصال بررسی می‌شوند.

## ۶. اتصال Bale

1. در بله ربات ایجاد و Token را دریافت کنید.
2. Chat ID کارشناسان یا گروه پشتیبانی را وارد کنید.
3. اتصال و روش دریافت پیام را فعال کنید.
4. ارسال پیام سایت و بازگشت پاسخ Reply را آزمایش کنید.

Webhook بله با کلید تصادفی محافظت می‌شود و Updateهای تکراری دوباره پردازش نمی‌شوند.

## ۷. سرویس هوش مصنوعی

در نسخه رایگان، Provider فعال فقط Cloudflare Workers AI است. OpenRouter، Ollama و سرویس‌های سازگار با OpenAI در کمبوباکس با نشان PRO نمایش داده می‌شوند اما قابل انتخاب نیستند. دو حالت اصلی پاسخ‌گویی در دسترس است:

- **پیشنهاد پاسخ:** خروجی AI به‌صورت پیش‌نویس در اختیار اپراتور قرار می‌گیرد.
- **پاسخ خودکار:** خروجی مستقیماً برای کاربر ارسال می‌شود.

حالت خودکار را فقط پس از آزمون کیفیت، بررسی سیاست داده Cloudflare و تنظیم Prompt فعال کنید. اتصال Providerهای دیگر در نسخه PRO ارائه می‌شود.

## ۸. اعلان‌ها

اعلان داخلی مرورگر هنگام بازبودن صفحه کار می‌کند. برای Push پایدار می‌توان سرویس پشتیبانی‌شده را فعال کرد. HTTPS، Service Worker معتبر و اجازه صریح کاربر برای Web Push ضروری است.

## ۹. حریم خصوصی و امنیت

- حالت ذخیره IP را روی «عدم ذخیره»، «هش HMAC» یا «IP کامل» تنظیم کنید.
- دوره نگهداری داده‌ها را متناسب با نیاز واقعی کاهش دهید.
- رضایت کاربر را برای سناریوهای لازم فعال کنید.
- Tokenها و API Keyها در صورت پشتیبانی سرور رمزگذاری می‌شوند.
- عملیات مدیریتی با Nonce و Capability کنترل می‌شوند.
- لاگ فنی فقط با فعال‌بودن هم‌زمان Debug وردپرس و گزینه افزونه نوشته می‌شود.
- Credentialها پیش از ثبت در گزارش فنی حذف یا Redact می‌شوند.

## ۱۰. قابلیت‌های قفل‌شده PRO

سه بخش زیر در نسخه 1.0.0 فقط به‌صورت پیش‌نمایش محوشده با نشان طلایی PRO نمایش داده می‌شوند:

- تیکتینگ هوشمند
- نقشه حرارتی تعامل کاربران
- REST API خارجی و Webhook خروجی

نسخه رایگان هیچ تنظیم فعال، شورت‌کد، مسیر عمومی، جدول داده یا فایل اجرایی برای این سه قابلیت ندارد.

## ۱۱. داده‌های نصب‌شده

پایگاه داده فقط جدول‌های مرتبط با گفتگو، پیام، نگاشت ربات‌ها، گزارش‌ها، یادداشت‌ها، محدودسازی، امتیازها، وظایف، برچسب‌ها، پیوست‌ها، واکنش‌ها، پایگاه دانش و Audit را ایجاد می‌کند. جدول تیکت، دپارتمان و رویداد Heatmap ایجاد نمی‌شود.

## ۱۲. آزمون پیش از انتشار

- فعال‌سازی افزونه روی نسخه هدف WordPress و PHP
- ارسال پیام سایت و پاسخ از صندوق وردپرس
- آزمون Telegram و Bale در هر روش دریافت پیام فعال
- آزمون فارسی، عربی و انگلیسی و تغییر RTL/LTR
- آزمون AI ابتدا در حالت پیشنهاد پاسخ
- بررسی اعلان مرورگر روی مرورگرهای هدف
- کنترل Export و Erase حریم خصوصی
- بررسی `debug.log` برای نبود Credential
- اطمینان از غیرفعال‌بودن تعامل با محتوای محوشده PRO

## ۱۳. فونت اختصاصی

در تب توسعه‌دهنده می‌توان فایل WOFF2 یا TTF معتبر را بارگذاری کرد. افزونه پسوند، اندازه و امضای باینری فایل را بررسی و آن را در پوشه اختصاصی `wp-content/uploads/tiamis-fonts` نگهداری می‌کند.
