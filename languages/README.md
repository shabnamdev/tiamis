# Tiamis runtime languages

The plugin provides Persian (`fa`), Arabic (`ar`) and English (`en`) through `Tiamis_Chat_I18n`.

The administration language can be switched at runtime without reloading the page. Server-rendered menus use the persisted language, while the active page uses a localized JavaScript dictionary for text nodes, placeholders, titles and RTL/LTR direction.

The frontend widget has an independent language setting and localized interaction strings for all three languages.
