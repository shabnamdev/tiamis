# 🇬🇧 English

## Overview

Tiamis AI Live Chat is a complete WordPress communication platform that
combines live chat, AI assistance, ticket management, operator
workspace, messaging integrations, analytics, privacy tools and
developer APIs.

It is designed for businesses, agencies, online stores, SaaS platforms
and professional WordPress websites that need a scalable customer
support solution.

## Core Features

### Live Chat System

-   Floating website chat widget
-   Visitor conversations
-   Conversation history
-   Guest and registered user support
-   Shortcode integration
-   Responsive interface

### AI Assistant

-   AI draft replies
-   Automatic reply support
-   Smart operator assistance
-   Cloudflare Workers AI support
-   PRO AI providers:
    -   OpenRouter
    -   OpenAI compatible APIs
    -   Ollama

### Ticket System

-   Guest tickets
-   Registered user tickets
-   Tracking codes
-   Ticket status management
-   Operator replies
-   File attachments
-   Voice recording
-   Message status

### Operator Workspace

-   Multiple operators
-   Operator profiles
-   Conversation assignment
-   Internal notes
-   Priority management
-   Tags
-   Tasks
-   Customer history

### Messaging Integrations

-   Telegram Bot integration
-   Bale integration
-   Two-way communication workflow
-   Webhook support

### Heatmap & Analytics

-   Click tracking
-   Selector tracking
-   Viewport information
-   SPA navigation tracking
-   Analytics dashboard

### Notifications

-   Browser notifications
-   Web Push support
-   New message alerts

### Security

-   WordPress capability checks
-   Nonce validation
-   Rate limiting
-   SSRF protection
-   HMAC webhook signing
-   Credential encryption
-   Privacy export and erase tools

### Developer Features

-   REST API
-   Bearer token authentication
-   Webhook events
-   Extensible architecture

# 🇮🇷 فارسی

::: {dir="rtl"}
## معرفی

Tiamis AI Live Chat یک پلتفرم کامل ارتباط با مشتری برای وردپرس است که چت
آنلاین، هوش مصنوعی، سیستم تیکتینگ، مدیریت اپراتورها، اتصال پیام‌رسان‌ها،
تحلیل رفتار کاربران و API توسعه‌دهندگان را در یک افزونه ارائه می‌کند.

این افزونه برای فروشگاه‌ها، شرکت‌ها، سایت‌های خدماتی، آژانس‌ها و پروژه‌های
حرفه‌ای وردپرس طراحی شده است.

## قابلیت‌های اصلی

### چت آنلاین

-   ویجت چت سایت
-   ذخیره تاریخچه گفتگو
-   پشتیبانی کاربر مهمان و عضو
-   شورت‌کد نمایش چت
-   طراحی واکنش‌گرا

### هوش مصنوعی

-   پیشنهاد پاسخ هوشمند
-   کمک به اپراتورها
-   Cloudflare Workers AI
-   Provider های نسخه Pro:
    -   OpenRouter
    -   OpenAI Compatible API
    -   Ollama

### سیستم تیکتینگ

-   تیکت کاربران مهمان
-   تیکت کاربران عضو
-   کد پیگیری
-   وضعیت تیکت
-   فایل پیوست
-   ضبط صدا
-   وضعیت مشاهده پیام

### مدیریت تیم پشتیبانی

-   چند اپراتور
-   پروفایل اپراتورها
-   اختصاص گفتگو
-   یادداشت داخلی
-   اولویت
-   برچسب
-   وظایف

### اتصال پیام‌رسان‌ها
