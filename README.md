## Overview

Tiamis – AI Live Chat is a professional WordPress customer support plugin with AI-assisted replies, multilingual communication, Telegram and Bale integration, operator inbox management, browser notifications, privacy controls, and RTL/LTR support.

## Features

- AI-assisted customer replies
- Live chat widget
- Operator inbox
- Telegram integration
- Bale integration
- Persian, Arabic and English support
- RTL/LTR interface
- Browser notifications
- Conversation management
- Privacy controls
