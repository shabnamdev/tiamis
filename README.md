# 🇬🇧 English

## Overview

**Tiamis AI Live Chat** is an advanced WordPress customer support and
communication plugin designed to transform website visitors into engaged
customers through intelligent conversations.

Tiamis combines live chat, AI assistance, operator management, messaging
integrations, notifications, and multilingual support into a single
scalable WordPress solution.

The plugin is designed for businesses, agencies, SaaS websites, online
stores, and professional WordPress projects that need faster and smarter
customer communication.

------------------------------------------------------------------------

## 🚀 Core Features

### 🧠 AI Assisted Conversations

Improve customer communication with intelligent AI-powered assistance.

Features:

-   AI response suggestions
-   Faster operator replies
-   Smart conversation assistance
-   Improved customer experience

### 💬 Modern Live Chat Widget

A customizable chat interface designed for modern websites.

Includes:

-   Floating chat button
-   Real-time conversations
-   User-friendly interface
-   Mobile-friendly design

### 👥 Operator Management System

Manage customer conversations professionally.

Capabilities:

-   Multiple operators
-   Conversation assignment
-   Internal notes
-   Conversation status management
-   Customer history

### 📱 Messaging Platform Integration

Connect external communication channels.

Supported:

-   Telegram integration
-   Bale integration
-   Future messaging extensions

### 🌍 Multilingual & RTL Support

Built for global websites.

Supported languages:

-   English
-   Arabic
-   Persian

Features:

-   Full RTL support
-   LTR compatibility
-   Localized interface

### 🔔 Notification System

Keep operators informed.

Includes:

-   Browser notifications
-   Web Push support
-   New message alerts

### 🔐 Privacy & Security

Built following WordPress security practices.

Includes:

-   Capability checks
-   Nonce validation
-   Privacy controls
-   Secure data handling

پشتیبانی آنلاین، چت هوشمند و مدیریت ارتباط با مشتری است.

این افزونه برای فروشگاه‌ها، شرکت‌ها، وب‌سایت‌های خدماتی و پروژه‌های حرفه‌ای
وردپرس طراحی شده تا ارتباط با کاربران سریع‌تر، هوشمندتر و سازمان‌یافته‌تر
شود.
