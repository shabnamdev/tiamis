# 🇬🇧 English

## Overview

Tiamis AI Live Chat is a complete WordPress customer communication
platform that combines live chat, AI assistance, ticket management,
operator workspace, messaging integrations, analytics, privacy controls
and developer tools.

Designed for businesses, agencies, online stores, SaaS platforms and
professional WordPress projects.

## Main Features

### 💬 Live Chat System

-   Modern floating chat widget
-   Real-time visitor communication
-   Conversation history
-   Guest and registered user support
-   Shortcode integration
-   Responsive interface

### 🧠 AI Assistant

-   AI draft replies
-   Automatic reply assistance
-   Smart operator suggestions
-   Cloudflare Workers AI support
-   Pro AI providers:
    -   OpenRouter
    -   OpenAI Compatible API
    -   Ollama

### 🎫 Ticket System

-   Guest tickets
-   Registered user tickets
-   Tracking codes
-   Ticket status management
-   Operator replies
-   File attachments
-   Voice messages
-   Message delivery status

### 👥 Operator Workspace

-   Multiple operators
-   Operator profiles
-   Conversation assignment
-   Internal notes
-   Priority management
-   Tags
-   Tasks
-   Customer history

### 📱 Integrations

-   Telegram Bot integration
-   Bale integration
-   Webhook workflow
-   External communication support

### 📊 Analytics & Heatmap

-   Click tracking
-   User behavior analysis
-   Heatmap visualization
-   SPA navigation tracking
-   Performance insights

### 🔔 Notifications

-   Browser notifications
-   Web Push support
-   New message alerts

### 🔐 Security & Privacy

-   Capability checks
-   Nonce validation
-   Rate limiting
-   SSRF protection
-   HMAC webhook security
-   Credential protection
-   Privacy export and erase tools

# 🇮🇷 فارسی

::: {dir="rtl"}
## معرفی

Tiamis AI Live Chat یک پلتفرم کامل ارتباط با مشتری برای وردپرس است که چت
آنلاین، هوش مصنوعی، سیستم تیکتینگ، مدیریت اپراتورها، اتصال پیام‌رسان‌ها،
تحلیل رفتار کاربران و ابزارهای توسعه‌دهندگان را در یک افزونه ارائه می‌کند.

## قابلیت‌های اصلی

### 💬 چت آنلاین

-   ویجت چت مدرن
-   ارتباط لحظه‌ای با کاربران
-   ذخیره تاریخچه گفتگو
-   پشتیبانی مهمان و کاربر عضو
-   شورت‌کد نمایش چت

### 🧠 هوش مصنوعی

-   پیشنهاد پاسخ هوشمند
-   کمک به اپراتورها
-   Cloudflare Workers AI
-   Provider های نسخه Pro:
    -   OpenRouter
    -   OpenAI Compatible API
    -   Ollama

### 🎫 سیستم تیکتینگ

-   تیکت کاربران مهمان
-   تیکت کاربران عضو
-   کد پیگیری
-   وضعیت تیکت
-   فایل پیوست
-   پیام صوتی

### 👥 مدیریت تیم

-   چند اپراتور
-   تخصیص گفتگو
-   یادداشت داخلی
-   اولویت

-   وظایف

### 📱 اتصال‌ها

### 🔐 امنیت
